# Панель администратора (общая база)

Сервер на Node.js без внешних зависимостей. Данные хранятся в `data/db.json`, пароли хешируются (scrypt), права проверяются на сервере.

## Запуск
1. Установите Node.js 18 или новее.
2. В папке проекта выполните `npm start`, затем откройте http://localhost:3000.
3. При первом заходе создайте первого пользователя. Он получит должность «Разработчик». Остальных создаёт руководство, пароль нового пользователя равен его нику.

## Настройки (переменные окружения)
- `PORT`: порт, по умолчанию 3000.
- `TZ_NAME`: часовой пояс для проверки даты сдачи заданий, по умолчанию `Europe/Warsaw`.
- `COOKIE_SECURE=1`: включите, когда сайт работает по HTTPS.
- `DATA_FILE`: путь к файлу данных, по умолчанию `data/db.json`.

## Вход через Discord
1. На https://discord.com/developers/applications создайте приложение, во вкладке OAuth2 добавьте Redirect `https://ВАШ-ДОМЕН/auth/discord/callback`.
2. Задайте переменные `DISCORD_CLIENT_ID`, `DISCORD_CLIENT_SECRET`, `DISCORD_REDIRECT_URI` (тот же адрес).
3. У пользователя в профиле должен быть указан его Discord ID (числовой). Кнопка «Войти через Discord» появится на странице входа.

## Продакшн
- Запустите через pm2: `pm2 start server.js --name admin-panel`.
- Поставьте перед ним nginx с HTTPS (Let's Encrypt), проксируя на `127.0.0.1:3000`, и передавайте заголовок `X-Forwarded-For`.
- Делайте резервные копии `data/db.json`.
